# Modelli AI locali

Nessun modello è ancora selezionato o incluso. Conservare i pesi scaricati in `models/weights/`, escluso da Git.

Per ogni modello annotare: nome e versione, URL di provenienza, licenza, checksum SHA-256, formato/runtime, classi supportate, dimensione input, RAM/FPS/latenza misurati sulla UNO Q. Registrare anche risorse necessarie per avviarlo senza Internet.

Un modello generico non garantisce classi per carrozzine né rilevamento di cadute. Verificare le classi reali prima di usarle nel pitch. Integrare il brick o runtime scelto in `app.yaml` e nelle dipendenze solo dopo la prova sul dispositivo.
