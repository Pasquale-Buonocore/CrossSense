# Dati di prova e risultati

I video non vengono archiviati continuamente dal prototipo per default. Per i test, mantenere localmente:

- `raw/`: video originali e annotazioni, con provenienza/licenza.
- `processed/`: dati derivati e annotazioni elaborate.
- `runs/`: eventi e misure delle singole prove.

Queste directory sono escluse da Git. Usare `manifest.example.csv` come formato iniziale per documentare i file locali; aggiungere un manifest reale privo di dati personali quando i video sono scelti. Non inserire nel manifest credenziali o link di accesso riservati.
